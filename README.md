# CC.Taskflow

Aplikasi Taskflow Sederhana  
Dibuat dengan Laravel untuk latihan pengembangan aplikasi web berbasis framework PHP.

---

## 📌 Deskripsi

**CC.Taskflow** adalah project web sederhana berbasis Laravel untuk manajemen tugas (task management) dengan fitur:
- Menambahkan tugas
- Menandai tugas selesai
- Menghapus tugas
- Tampilan antarmuka yang sederhana & responsif

Project ini dibuat sebagai latihan CRUD menggunakan Laravel MVC.

---

## ⚙️ Stack & Teknologi

- **Laravel** (PHP Framework)
- **Blade Templating Engine**
- **MySQL** (Database)
- **HTML, CSS, JavaScript**

---

## 💡 Tujuan Pembuatan

Project ini dibuat untuk:
- Mempelajari konsep MVC di Laravel
- Melatih pembuatan fitur CRUD dasar
- Membiasakan penggunaan migration & seeder
- Membuat dokumentasi portofolio di GitHub
